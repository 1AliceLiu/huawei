# 本地预览区域标定

用户已要求实现此前讨论的鼠标标定流程，并确认使用本地 `realtime_web.py` 预览。

每路画面增加标定入口；冻结实际推理坐标系中的原始帧，鼠标绘制一个多边形 ROI、一条有限计数线和一个方向箭头。支持闭合、撤销、清空、保存和重新加载；保存的图形实时叠加到预览。此次不实现车辆过滤、跟踪修改或流量累计。

沿用现有 Python HTTP 服务和截图机制，增加独立的标准库标定存储/接口模块与原生 Canvas 页面，不增加依赖。相比独立标注软件，本地网页无需搬运坐标；相比前端本地存储，服务端 JSON 能供后续计数程序读取。

按视频源及裁剪方式生成稳定键，归一化坐标，按摄像头隔离并原子保存。拒绝无效几何、非有限坐标、跨源浏览器写入及超大请求；损坏配置不得静默覆盖。相同宽高比支持缩放，比例变化停止叠加并提示重新标定。用户已有修改保留在当前工作区，运行中的服务不自动终止。
